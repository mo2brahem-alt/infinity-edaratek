# قرارات طبقة الحساب والتفويض

## مسار أهلية واحد

`app/Services/Mobile/AccountAccessEvaluator.php` هو المقيم المشترك القائم منذ Phase 2، وأعيد استخدامه بدل إنشاء نظام موازٍ. استدعاء User::requiresSuperAdminApproval وUser::hasApprovedAccountAccess يمر منه، وكذلك إصدار PAT وحراسة طلبات native. Middleware الويب يعيد تحميل الحساب وأدواره وصلاحياته من DB لكل طلب ويحدّث هوية حارس الويب الحالي مع الحفاظ على session/CSRF.

تُفحص أدوار Spatie الحالية من العلاقة بقاعدة البيانات مع عمود legacy. أي school_manager/supervisor يفرض approved للحساب كاملًا. pending/rejected يسبقان inactive في سبب الرفض. null أو قيمة موافقة مجهولة لحساب حساس لا تُحوّل إلى approved. لا تغيير تلقائي لحالة الموافقة أو النشاط عند تغيير الأدوار، وprimaryRole يبقى للعرض/التوجيه فقط. لا ترقية لـschool_admin.

`UserApprovalService` يحتفظ بانتقالات الاشتراك والمدرسة الحالية، ويتحقق الآن من منفذ حالي نشط ومخول super_admin داخل الخدمة نفسها. طابور الإدارة الحالي يبحث بعملية OR عن الدور الحساس في legacy أو Spatie باستخدام exists، فلا يحتاج تعديلًا؛ الاختبار يثبت اكتشاف التمثيلات الثلاثة دون تكرار.

## حقول السلطة والتفويض الحالي

`UserAuthorityFields` يرفض وجود حقول السلطة المحظورة حتى إذا كانت null أو قائمة فارغة. يُستدعى من profile والتسجيل الذاتي العام/مدير/مشرف وطلبات تعديل المستخدم المدرسي وإسناد الأدوار. تبقى قوائم الحقول المسموحة الخاصة بمدير المدرسة مقيدة بالخدمة والـcatalog الحالية؛ لا إزالة لدعم staff+teacher ولا تبديل لنظام Spatie.

استثناء توافق مقصود: إنشاء المستخدم المدرسي يتجاهل school_id/اشتراك العميل وفق عقد الويب القائم؛ school_id غير موجود في rules/validated وتُحسب المدرسة والاشتراك من المدير الحالي. اختبار SubscriptionBillingAndSeatsTest غير المعدل يثبت إنشاء المستخدم وحجز المقعد في المدرسة المأذونة فقط رغم معرفات أجنبية. لا يسمح هذا الاستثناء بكتابة سلطة tenant من العميل.

اختبارات المرحلة تستعمل المسارات الحقيقية الحالية، ولا تُنشئ مسارات أعمال وهمية تمنح صلاحيات. تزال الصلاحية أو الدور بين طلبين وتُفحص النتيجة الجديدة. اختبارات المدرسة الحالية تغطي إزالة العضوية/الملكية والتعليق وحقول school_id المزورة ورفض مستخدم أجنبي. لا تعني هذه العينات إغلاق مصفوفة Phase 4 أو معالجة stale delegated groups.

## استعادة كلمة المرور

نتيجة forgot-password العامة واحدة للبريد الموجود وغير الموجود ونتيجة cooldown من broker. يبقى إرسال reset عبر Laravel Notification وقبول token الصحيح كما في السابق. يطبق middleware حد 3 طلبات لكل بريد/ساعة و10 لكل IP/ساعة؛ كلاهما قبل lookup ويشمل العناوين غير الموجودة. مفاتيح HMAC لا تحمل بريدًا/IP خامًا، واختبارات تبديل IP/البريد والاستعادة بعد الساعة مثبتة في PasswordResetTest.

## الخطأ الداخلي والسجل

الحارس الخاص بـv1 في bootstrap/app.php يعيد 500/INTERNAL_ERROR وrequest_id مولدًا، حتى مع debug=true. يوقف تقرير الاستثناء الخام لمسار v1 ويسجل حدثًا ثابتًا فقط دون نص الاستثناء أو request body أو headers. اختبار EnvironmentSafetyTest يتعمد تضمين SQL ومسار وهمي وقيمة عشوائية داخل الاستثناء ويتحقق من غيابها في الاستجابة والسجل.

AuthSecurityLog يقبل قائمة ثابتة من الأحداث ومعرف مستخدم رقمي فقط، ويحد تكرار حدث الرفض لمدة 60 ثانية. لا يسجل أسباب الموافقة الحرة أو كلمات المرور أو PAT أو OTP أو بريدًا/IP. هذا الحد الأدنى المطلوب لـT037/T038؛ لا تقديم شامل لـT094 أو شهادة إعدادات بيئة حية.

## نقاط الدخول المشمولة بهذه المرحلة

| نقطة الدخول الحالية | عوامل الحماية الحالية/المشتركة | دليل سلبي مطلوب |
|---|---|---|
| native me/devices | Bearer فعلي، أهلية الحساب المتجددة، مالك PAT | رفض cookie والحساب المحظور وPAT أجنبي |
| اعتماد/رفض إداري | session، دور admin حالي، أهلية الحساب، تحقق منفذ داخل الخدمة | رفض موظف ورفض منفذ فقد دوره |
| profile/التسجيل الذاتي | session عند الحاجة، حقول ذاتية محددة، سلطة حساب منشأة بالخادم | حقول أدوار/اعتماد/مدرسة لا تغيّر DB |
| المستخدمون المدرسيون | حراسة manager، ملكية المدرسة ونشاطها، catalog الأدوار/التفويض، هوية المورد | معرف مستخدم أجنبي، دور نظام حساس، نشاط/اعتماد مزور |
| الهيكل المدرسي الحالي | أهلية الحساب، علاقة المدرسة، دور موظف وتفويض عملية | إزالة الصلاحية تمنع الطلب اللاحق |

لا تغييرات على Policies أو استعلامات الموارد؛ أعيد استخدام حراسها وخدماتها الحالية مع المستخدم المحدث. T041 وما بعده مسؤول عن حصر جميع طرق CRUD/tasks/files، وعلاقة parent-school، وعزل مجموعات التفويض بعد النقل، وليس هذا الحصر المحدود.
